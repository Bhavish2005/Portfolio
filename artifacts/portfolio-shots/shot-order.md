# Portfolio Video Shot Order

Use these frames in order for a short portfolio reel. Keep the motion subtle: slow zooms, quick crossfades, and a clean cursor reveal on the assistant interactions.

## Sequence
1. `01-home-top.png`
   - Open with the hero section.
   - Duration: 2.5-3s
   - Motion: slow push-in.

2. `02-about-metrics.png`

   - Duration: 2.5s
   - Motion: slight vertical drift.

3. `03-skills-technical-arsenal.png`

   - Duration: 2s
   - Motion: pan across the skill bands.

4. `04-featured-work.png`
   - Showcase the featured projects.
   - Duration: 3s
   - Motion: gentle zoom, pause on project cards.

5. `05-contact.png`

6. `06-leo-open.png`
   - Introduce the LEO AI assistant.
   - Duration: 2s
   - Motion: quick zoom on the floating pill and drawer.

7. `07-leo-qa-answer.png`
   - Show a real question-and-answer moment.
   - Duration: 3s
   - Motion: hold long enough to read the response.

8. `08-leo-jd-analyzer.png`
   - Close with the JD Analyzer feature and the compatibility score.
   - Duration: 3s
   - Motion: slow push-in on the match score and matched skills.

## Suggested Edit Rhythm
- Total runtime: about 20-22 seconds.
- Transitions: crossfade or whip-pan only between section changes.
- Music: light tech ambient or minimal cinematic pulse.
- Text overlays: use only 2-3 words per segment if needed, such as "Built to Perform", "AI Portfolio", and "LEO Assistant".
